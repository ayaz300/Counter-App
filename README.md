# 🔢 Counter App

A sleek, simple, and highly interactive **Counter web application** built from scratch using pure **HTML5, CSS3, and JavaScript**. This project focuses on modern UI design, smooth micro-interactions, and instant state updates.

## 🚀 Features

- **Increment & Decrement:** Effortlessly scale your counts up or down with dedicated control keys.
- **Micro-Interactions:** Enjoy fluid bounce animations on every click and smooth transitions on hover.
- **Visual Feedback:** Built-in dynamic font popping that triggers whenever the value changes.
- **Responsive Layout:** Optimized UI that centers perfectly across mobile screens, tablets, and desktops.
- **Zero Dependencies:** Ultra-lightweight and blazingly fast, utilizing purely native web code.

## 🛠️ Technologies Used

- **HTML5:** Structures the semantic container layout and application layout elements.
- **CSS3:** Delivers modern flexbox centering, custom color gradients, shadows, and keyframe animations.
- **JavaScript (ES6+):** Handles dynamic DOM manipulation, class injections, and live variable tracking.

## 💻 How to Run

1. **Clone the repository:**
   ```bash
   git clone http://github.com/ayaz300/Counter-App
   ```
2. **Navigate into the project folder:**
   ```bash
   cd Counter
   ```
3. **Launch the app:**
   Open the `index.html` file directly in any modern web browser (Chrome, Edge, Safari, Firefox). No installations or local servers are required!

## 🎯 How It Works

1. Click the green **+** button to increase the counter total by 1.
2. Click the red **-** button to decrease the counter total by 1.
3. Watch the display number execute a fluid scale-pop animation instantly on click.
